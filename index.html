매달 알림으로 받기
이 앱은 열어봐야 보입니다. 결제수단을 바꿔야 하는 시점은 매달 초인데, 정작 그때 앱을 열 이유가 없습니다. 그래서 같은 계산을 GitHub Actions 가 매달 돌려 텔레그램으로 보내도록 만들어 뒀습니다 — 매달 1일, 10월 말(홈택스 미리보기 개설), 12월 중순(마감)에 옵니다.
알림을 돌리는 서버는 이 기기에 저장된 값을 볼 수 없습니다. 그래서 숫자를 한 번 건네줘야 합니다. 「알림에 반영」을 누르면 아래 내용이 저장소로 보내져 다음 알림부터 그 값으로 계산합니다. 처음 한 번은 아래에 GitHub 토큰을 넣어야 합니다.
토큰을 두기 싫으면 「복사」해서 저장소의 config.json 에 직접 붙여넣어도 결과는 같습니다.
GitHub 토큰 이 기기에 한 번만 넣으면 됩니다. 발급 방법은 아래를 펴세요.
토큰 발급하는 법 (한 번만)
1 github.com 로그인 → 오른쪽 위 프로필 → Settings
2 왼쪽 맨 아래 Developer settings
3 Personal access tokens → Fine-grained tokens → Generate new token
4 Repository access → Only select repositories → yearend-card-alert 선택
5 Permissions → Repository permissions → Contents 를 Read and write 로
6 만들어진 github_pat_ 로 시작하는 문자열을 위 칸에 붙여넣고 「이 기기에 저장」
권한을 좁히세요 위 4·5번대로 하면 이 토큰으로는 그 저장소의 파일 수정 말고는 아무것도 할 수 없습니다. 다른 저장소도, 계정 설정도 건드리지 못합니다. 토큰은 이 기기 안에만 저장되고 앱 주소나 코드에는 들어가지 않습니다.
만료일을 정했다면 그날 이후로는 「알림에 반영」이 실패합니다. 그때 같은 방법으로 새로 발급해 넣으면 됩니다. 알림 자체는 토큰과 무관하게 계속 옵니다.
