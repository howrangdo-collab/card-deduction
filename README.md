# 카드공제 조타실

연말정산 신용카드 소득공제를 최대로 받기 위해, 남은 기간의 결제수단(신용 / 체크·현금영수증)과
맞벌이 부부의 카드 명의 배분을 계산합니다.

**https://howrangdo-collab.github.io/card-deduction/**

- 설치·서버·회원가입 없음. 폰 브라우저에서 열고 「홈 화면에 추가」하면 앱처럼 씁니다.
- 입력한 숫자는 **그 브라우저 안(localStorage)에만** 저장됩니다. 서버로 나가지 않습니다.
- 이 저장소는 화면만 담습니다. 계산 엔진의 정본과 매달 알림(텔레그램)은 별도 비공개 저장소에 있습니다.

## 이 앱이 하지 않는 것

소비를 늘리라고 권하지 않습니다. 체크카드 기준 한계 회수율은 `30% × 한계세율`이라
세율 16.5% 구간에서 약 5%입니다. 100만원 더 쓰고 5만원 돌려받는 구조이므로,
공제를 노린 추가 지출은 언제나 손해입니다.
이 앱은 **어차피 쓸 돈을 어떤 수단으로, 누구 명의로 결제할지**만 정합니다.
